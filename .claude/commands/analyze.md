Ты - архитектор Laravel. Проведи комплексный анализ проекта.

## Анализируй по следующим категориям:

### 1. Архитектура проекта
- Соответствует ли структура папок стандартам Laravel?
- Есть ли нарушения MVC?
- Правильно ли разделены бизнес-логика и представления?
- Используются ли репозитории или сервисы для сложной логики?

### 2. Маршруты (Routes)
- Правильно ли сгруппированы маршруты?
- Есть ли защита через middleware?
- Используются ли resource-контроллеры где нужно?
- Нет ли дублирования маршрутов?
- Правильно ли используются именованные маршруты?

### 3. Контроллеры
- Не слишком ли "толстые" контроллеры?
- Используются ли Form Request для валидации?
- Есть ли инъекция зависимостей через конструктор?
- Используются ли ресурсы (API Resources)?

### 4. Модели и Eloquent
- Правильно ли определены связи?
- Есть ли атрибуты `$fillable`, `$guarded`, `$casts`?
- Используются ли скоупы для часто используемых запросов?
- Нет ли N+1 проблем? (проверь наличие `with()`)
- Используются ли события (observers)?

### 5. База данных
- Есть ли индексы для часто запрашиваемых полей?
- Правильно ли используются миграции?
- Нет ли неоптимальных запросов?
- Используются ли транзакции для сложных операций?

### 6. Безопасность
- Правильно ли настроена аутентификация?
- Есть ли защита от CSRF?
- Используются ли политики (Policies) для авторизации?
- Нет ли SQL-инъекций и XSS уязвимостей?
- Безопасно ли хранятся пароли?

### 7. Тесты
- Какой процент покрытия тестами?
- Есть ли тесты для критических путей?
- Используются ли фабрики и сидеры?
- Есть ли интеграционные тесты?

### 8. Производительность
- Есть ли кэширование (Redis, Memcached)?
- Используется ли очереди (Queues) для тяжелых задач?
- Оптимизированы ли загрузки изображений?
- Используются ли CDN для статики?
- Есть ли мониторинг производительности?

### 9. Зависимости
- Актуальные ли версии пакетов?
- Есть ли устаревшие или неиспользуемые пакеты?
- Нет ли конфликтов версий?

### 10. Документация
- Есть ли README с инструкцией по установке?
- Описаны ли API эндпоинты?
- Есть ли комментарии в сложных местах?

## В конце выдай:

4. **Рекомендации по улучшению**
5. **План действий** на ближайшие недели
