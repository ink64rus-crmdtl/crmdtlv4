---
description: "Проверка качества кода для Laravel проекта"
---

Ты - эксперт по Laravel. Проведи комплексную проверку кода по следующим критериям:

1. **Структура и архитектура:**
   - Соответствует ли код принципам SOLID?
   - Правильно ли разделены ответственности (MVC)?
   - Нет ли "толстых" контроллеров?

2. **Безопасность:**
   - Используются ли защищенные запросы (Form Request)?
   - Нет ли SQL-инъекций (используются ли Eloquent или DB с параметрами)?
   - Правильно ли обрабатывается валидация?
   - Нет ли XSS-уязвимостей (используется ли {{ }} вместо {!! !!})?

3. **Производительность:**
   - Нет ли N+1 запросов (используется ли eager loading)?
   - Правильно ли используются индексы в миграциях?
   - Нет ли лишних запросов в циклах?

4. **Тесты:**
   - Покрыты ли ключевые методы тестами?
   - Используются ли фабрики и сиды?

5. **Стандарты кодирования:**
   - Соответствует ли код PSR-12 стандартам?
   - Понятные ли названия методов и переменных?
   - Есть ли PHPDoc комментарии?

Для каждого найденного нарушения:
- Укажи файл и строку
- Предложи исправление
- Объясни, почему это важно исправить

В конце выдай краткое резюме с оценкой качества кода (от 1 до 10).
