# Baseline: Settings/Branches/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/branches).

Скриншот: `screenshots/settings-branches.jpg`

## Структура
- Пагинация: серверная (`paginate(15)->withQueryString()`), но на studio2 всего 2 строки — второй страницы физически нет, `<Pagination>` не отрисовывает ссылки при одной странице (норма, не баг).
- Тулбар: `DataTableToolbar` — поле поиска («Поиск по названию, городу, тел...») + кнопка «Фильтры» + кнопка «Настроить столбцы» (иконка справа).
- Чекбокс-колонка: **да** (селект всех строк, `selectAll`).
- Колонка «Действия»: карандаш (редактировать) + корзина (удалить), обе — иконки в цветных круглых плашках.
- Строк на момент фиксации: **2** («Точка 2 Тест», «МДТЛ»).
- Разметка `<th>` — статичная, каждая колонка захардкожена по отдельности (НЕ `activeColumns`-цикл).

## Колонки (порядок слева направо)
1. чекбокс
2. Название (текст, полужирный)
3. Юрлицо — «МДТЛ» показывает ДВА юрлица списком (у локации может быть несколько), «Точка 2 Тест» показывает серый плейсхолдер «Без юрлица»
4. Адрес
5. Телефон (или «—»)
6. Статус — зелёный бейдж «Активно»
7. Действия — иконки

## Консоль браузера на момент фиксации
Только Vite HMR debug, без warning/error.

## На что смотреть после рефакторинга
- Многострочная ячейка «Юрлицо» у МДТЛ (два юрлица одно под другим) не ломается компонентом со слотами.
- Серый плейсхолдер «Без юрлица» у локации без юрлица — не путать с ошибкой рендера.
- Поиск/«Фильтры»/«Настроить столбцы» продолжают открываться и работать как раньше (компонент не трогает тулбар).
- Чекбоксы и массовые действия работают.
