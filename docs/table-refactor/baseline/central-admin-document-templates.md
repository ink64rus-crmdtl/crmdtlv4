# Baseline: Central/Admin/DocumentTemplates/Index.vue

Зафиксировано: 2026-08-14, central-домен (localhost:8000/admin/document-templates).

Скриншот: `screenshots/central-admin-document-templates.jpg`

## Структура
- Central-админка (CentralAdminLayout, отдельный от тенантского сайдбар).
- Header-карточка + отдельная карточка с блоком клиентских фильтров (`filterCountry`/`filterEntityType`, добавлены в этой же сессии ранее) — `<select>` × 2 + кнопка «Сбросить» (условная, `v-if="filterCountry || filterEntityType"`), НЕ `DataTableToolbar`.
- `templates` — простой массив (весь список), `filteredTemplates` — клиентский computed-фильтр. НЕТ пагинации, НЕТ чекбокс-колонки.
- **ДВА пустых состояния** (как в Settings/Payroll): «Шаблонов ещё нет...» (весь список пуст) ИЛИ «По выбранным фильтрам ничего не найдено» (список непуст, но фильтр не даёт совпадений) — `v-if`/`v-else-if`.
- Строк на момент фиксации: 8 (шаблоны по странам — Беларусь×2, Грузия×2, Казахстан×2, Россия×2, все Заказ-наряд/HTML/Активен).

## Колонки
1. Название — полужирный
2. Страна — синий (`bg-secondary/10`) бейдж с названием страны ИЛИ серый текст «Все страны», если `country_code === null`
3. Сущность — текст (`entityTypes[template.entity_type]`)
4. Источник — бейдж: синий Word ИЛИ серый HTML (тот же паттерн, что в Settings/DocumentTemplates)
5. Статус — зелёный/серый бейдж
6. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- НЕТ `selectable`.
- Блок фильтров (2 select + условная кнопка «Сбросить») — вне `<table>`, не трогается, продолжает фильтровать `filteredTemplates`.
- ДВА пустых состояния через `#empty`-слот с условием внутри (`v-if="templates.length === 0" v-else`).
- Полноэкранная модалка редактора (`DocumentTemplateEditor.vue`) — не задета.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (8 шаблонов по странам). Оба пустых состояния и фильтры проверены вживую: выбор «Россия» корректно сузил список до 2 записей с появлением кнопки «Сбросить»; добавление фильтра «Клиент» (нет ни одного шаблона такой сущности для России) дало «По выбранным фильтрам ничего не найдено» через `#empty`-слот. Ни одной ошибки в консоли. Регресс не обнаружен.
