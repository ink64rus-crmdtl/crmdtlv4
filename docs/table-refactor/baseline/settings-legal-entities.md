# Baseline: Settings/LegalEntities/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/legal-entities).

Скриншот: `screenshots/settings-legal-entities.jpg`

## Структура
- «Настройки компании», вкладка «Юридические лица».
- Тулбар: поиск + «Добавить юрлицо», `:has-filters="false"`.
- Чекбокс-колонка: да. Колонки — статичные.
- Строк на момент фиксации: 2 (ИП Гурьев Михаил Николаевич — Россия/645004993512/МДТЛ/2 сч./Активно; ООО Мобиклин Детейлинг — Россия/645004993513/МДТЛ/0 сч./Активно).

## Колонки
1. чекбокс
2. Название — полужирный + иконка `ri-bank-line text-primary`
3. Юрисдикция — серый бейдж (`countryConfig?.name || tenantCountry`)
4. Налоговый номер — текст (или «—»)
5. Локации — список бейджей с иконкой магазина (или серое «—», если пусто)
6. Расчетные счета — «N сч.» с иконкой кошелька
7. Статус — зелёный/красный бейдж
8. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.
