# Baseline: Settings/BusinessDirections/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/business-directions).

Скриншот: `screenshots/settings-business-directions.jpg`

## Структура
- Страница «Настройки компании» — `SettingsNav` (много вкладок), «Направления» активна.
- Header-карточка + `PageHelper` над тулбаром.
- Тулбар: поиск + «Добавить направление» — `:has-filters="false"` (нет кнопки «Фильтры»), без «Настроить столбцы» (колонки статичные).
- Чекбокс-колонка: да. Колонка «Действия»: 2 иконки (карандаш/корзина).
- Колонки — СТАТИЧНЫЕ.
- Строк на момент фиксации: 3 (Шиномонтаж/Автомойка/Детейлинг — все «Во всех локациях», «Активно»).

## Колонки
1. чекбокс
2. Название — полужирный + иконка `ri-node-tree text-primary`
3. Локации — список бейджей с иконкой магазина (`direction.branches`) ИЛИ серый текст «Во всех локациях», если пусто
4. Статус — зелёный/красный бейдж
5. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- Список локаций-бейджей (v-if/v-else с «Во всех локациях») сохраняется в слоте `#cell-branches` как условный блок.
- Иконка `ri-node-tree` перед названием не теряется.
