# Baseline: Settings/Posts/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/posts).

Скриншот: `screenshots/settings-posts.jpg`

## ⚠️ ИСКЛЮЧЕНА ИЗ МИГРАЦИИ ЭТОГО ПАКЕТА
`<tbody>` здесь — не обычный элемент, а `<draggable tag="tbody" v-model="sortedPosts" handle=".post-drag-handle" @end="onPostsReordered">` (vuedraggable) — drag-n-drop сортировка постов мышью. `DataTable.vue` в текущей реализации сам жёстко рендерит `<tbody>` внутри своего шаблона — нет способа подменить его на `<draggable>` без изменения самого компонента. Тот же класс сложности, что `Operations/WorkOrders` (сознательно отложен до отдельного этапа) и `Warehouse/Products` категорий (там `<draggable>` тоже используется — но НЕ на таблице постов/товаров, см. проверить отдельно при следующем заходе). Решение: НЕ мигрировать эту страницу в текущем пакете; либо добавить в `DataTable.vue` опциональный проп `draggable`/`sortable-rows` отдельным небольшим приростом функциональности, когда возникнет следующая drag-таблица, либо оставить как есть постоянно (drag-n-tbody — редкий частный случай, не факт что стоит усложнять общий компонент ради одной страницы).

## Структура (справочно, для будущей миграции)
- «Настройки компании», вкладка «Посты».
- Тулбар: поиск + «Добавить пост» + «Фильтры» + «Настроить столбцы» (судя по иконке — уточнить активна ли).
- Чекбокс-колонка: да, ПЛЮС отдельная колонка-хэндл слева (`w-8`, без заголовка) для иконки перетаскивания `ri-draggable`.
- Колонки — статичные. ДВА условных tbody: пустой (`v-if="posts.data.length === 0"`, обычный `<tbody>`) / непустой (`v-else`, `<draggable tag="tbody">`).
- Строк на момент фиксации: 2 (Пост 1 — МДТЛ/Детейлинг/Активен; Пост 2 Мойка — МДТЛ/Автомойка/Активен).

## Колонки
1. drag-handle (без заголовка, иконка `ri-draggable`)
2. чекбокс
3. Название — иконка (`post.icon` или `ri-tools-fill`, цвет — `post.calendar_color` инлайн-стилем или `text-primary`) + текст
4. Локация — бейдж с иконкой магазина (или серое «Общий (без локации)»)
5. Направления — список синих (`bg-info/10`) бейджей с иконкой `ri-node-tree` (или серое «Любое направление»)
6. Статус — зелёный/красный бейдж
7. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть при будущей миграции (если решат добавить drag в DataTable)
- Порядок постов после перетаскивания сохраняется через `@end="onPostsReordered"` — POST-запрос с новым порядком id.
- Иконка поста рендерится с инлайн `:style` цветом ИЛИ tailwind-классом `text-primary` — взаимоисключающе.
