# Baseline: Finance/Snapshots/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/finance/snapshots).

Скриншот: `screenshots/finance-snapshots.jpg`

## Структура
- Страница «Финансы и Кассы», вкладка «Остатки по дням», активная.
- Отдельная карточка-фильтр над таблицей (простой `<select>` «Счет», без `DataTableToolbar`, без поиска, без «Настроить столбцы» — подтверждён исходником, это один из 2 известных исключений из общего тулбар-паттерна).
- **Нет чекбокс-колонки, нет колонки «Действия»** — чисто read-only отчёт.
- Колонки — СТАТИЧНЫЕ (`<th>` по одному в разметке, не `activeColumns`) — единственная из 3 Finance-страниц без динамических колонок.
- Пагинация: серверная (`<Pagination :meta="snapshots" />`), но на момент фиксации 0 строк.
- Пустое состояние — НЕ простой текст: внутри сообщения инлайновый `<code>` с командой `php artisan tenants:run snapshots:accounts` — обязательно передать через слот `#empty`, а не строковый `emptyMessage` (тот не поддерживает HTML/дочерние теги).
- Строк на момент фиксации: 0.

## Колонки
1. Дата
2. Счет — `font-medium`
3. Остаток на начало — `text-right`
4. Приход — `text-success text-right`, с «+» перед суммой
5. Расход — `text-danger text-right`, с «−» перед суммой
6. Переводы вх./исх. — `text-gray-500 text-right`, формат «+X / −Y» в одной ячейке
7. Остаток на конец — `font-bold text-right`

## Консоль браузера на момент фиксации
Только Vite HMR debug (несколько повторных connect/connected — открывались разные вкладки этой сессии, не ошибка).

## На что смотреть после рефакторинга
- Верхний `<select>`-фильтр по счёту не задет (он вне `<table>`).
- `#empty` слот обязателен (не `emptyMessage`) — иначе потеряется `<code>`-тег с командой.
- Никакой чекбокс-колонки/колонки «Действия» — `selectable`/`has-actions` НЕ ставить.
- Все 7 колонок с одинаковым `text-right` выравниванием, кроме первых двух — свериться с `align` на каждой колонке индивидуально.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (пустое состояние с фильтром «Счет» над таблицей), ни одной ошибки в консоли. Слот `#empty` корректно отрендерил inline `<code>php artisan tenants:run snapshots:accounts</code>` внутри текста — подтверждено, что слот (не строковый `emptyMessage`) необходим именно для этого случая. Регресс не обнаружен.
