## Структура
- Та же страница «Клиенты и Автомобили», вкладка «Автомобили» активна (см. `crm-clients.md` про вкладки).
- Информационная плашка сверху содержит ДВЕ строки: обычный текст + зелёная строка «✓ Включена строгая проверка госномеров (маска RU)» — это не часть таблицы, но рядом.
- Пагинация: серверная, 1 строка на momento — второй страницы нет.
- Тулбар: `DataTableToolbar` — поиск («Поиск по госномеру, VIN...») + «Фильтры» + «Настроить столбцы».
- Чекбокс-колонка: **да**.
- Колонка «Действия»: 3 иконки (глаз/карандаш/корзина), как и у Clients.
- Колонки — динамические (`activeColumns`), меньший набор, чем у Clients.
- Строк на момент фиксации: **1** (Audi Q5, Иванов Сергей Вячеславович, А001АА64).
