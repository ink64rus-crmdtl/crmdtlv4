# Baseline: HR/Positions/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/hr/positions).

Скриншот: `screenshots/hr-positions.jpg`

## Структура
- Страница «Сотрудники и HR» — вкладки сверху (Сотрудники / Справочник должностей / Взаиморасчёты), эта — вторая, активная.
- Отдельная header-карточка с заголовком/описанием НАД тулбаром (не часть таблицы).
- Тулбар: поиск («Поиск по названию...») + «Добавить должность» + «Фильтры» (Offcanvas: роль в расчёте ЗП, статус) — БЕЗ «Настроить столбцы» (колонки статичные).
- Чекбокс-колонка: да.
- Колонки — СТАТИЧНЫЕ (не `activeColumns`).
- Колонка «Действия»: 2 иконки (карандаш/корзина), с круглой/квадратной цветной подложкой (стандартный паттерн).
- Строк на момент фиксации: 2 («Менеджер» — Исполнитель/Активно; «Руководитель» — Администратор/Активно).

## Колонки
1. чекбокс
2. Название — полужирный + иконка медали (`ri-medal-line text-primary`) перед текстом
3. Роль в расчёте ЗП — бейдж (синий «Администратор» / серый «Исполнитель»)
4. Статус — зелёный/красный бейдж «Активно»/«Неактивно»
5. Действия — 2 иконки

## Консоль браузера на момент фиксации
Только Vite HMR debug (много повторных connect/hot-updated css — открывались/обновлялись другие вкладки этой сессии, не ошибка).

## На что смотреть после рефакторинга
- Иконка медали перед названием должности не потеряется при переносе в слот `#cell-name`.
- Пустое состояние — свой текст («Должности еще не добавлены. Нажмите "Добавить должность".») через `empty-message`.
- Offcanvas «Фильтры» продолжает работать.

Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (те же 2 строки, бейджи роли/статуса, иконка медали перед названием), ни одной ошибки в консоли. Регресс не обнаружен.
