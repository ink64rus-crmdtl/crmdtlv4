# Baseline: CRM/Clients/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/crm/clients).

Скриншоты: `screenshots/crm-clients-left.jpg` (левая часть таблицы) + `screenshots/crm-clients-right.jpg` (после горизонтального скролла — правая часть с колонкой «Действия»).

## Структура
- Страница «Клиенты и Автомобили» — ДВЕ вкладки над таблицей: «Клиенты» (активна) / «Автомобили» (см. отдельный baseline `crm-vehicles.md`) — переключение вкладки меняет URL (`/crm/clients` ⇄ `/crm/vehicles`), это НЕ часть таблицы, но соседствует с ней и не должно быть задето рефакторингом `<table>`.
- Пагинация: серверная, на studio2 всего 4 строки — второй страницы нет.
- Тулбар: `DataTableToolbar` — поиск («Поиск по имени, телефону, ema...») + «Фильтры» + «Настроить столбцы».
- Чекбокс-колонка: **да**.
- Колонка «Действия»: ТРИ иконки в цветных плашках (глаз/просмотр, карандаш/редактировать, корзина/удалить).
- Колонки — **динамические** (`activeColumns`, система ListView/FieldPermissionService), а не захардкожены поштучно — компонент обязан принимать колонки как проп-массив, не как явный список слотов.
- Горизонтальный скролл — колонок больше, чем помещается в 1568px viewport, таблица скроллится вбок внутри своего контейнера (сама страница — нет).
- Строк на момент фиксации: **4**.

## Колонки (порядок слева направо, из `activeColumns` по умолчанию)
1. чекбокс
2. Клиент — составная ячейка: цветной круглый аватар с инициалом буквы + имя/название (у юрлица — капсом, длинное)
3. Роль клиента — простой текст («Поставщик», «Подрядчик», «Клиент»)
4. Группа лояльности — «—» у всех 4 (нет группы)
5. Сегмент — синий бейдж «Новичок» у всех 4
6. Телефон — текст или «—»
7. Тип (B2B/B2C) — иконка + текст («Юрлицо»/«Физлицо»)
8. Баланс — «0 ₽» зелёным
9. Локация — иконка + «МДТЛ»
10. Действия — 3 иконки

## Консоль браузера на момент фиксации
Только Vite HMR debug, без warning/error.

## На что смотреть после рефакторинга
- Составная ячейка «Клиент» (аватар+имя) корректно рендерится через слот, а не превращается в голый текст.
- Динамический список колонок (`activeColumns`) действительно управляет тем, что рендерит `<DataTable>` — переключить «Настроить столбцы» и убедиться, что набор колонок в таблице меняется как раньше.
- Обе вкладки (Клиенты/Автомобили) продолжают переключаться и вести на правильные URL.
- Горизонтальный скролл таблицы не пропал и не стал скроллить всю страницу целиком.
