# Baseline: HR/Employees/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/hr/employees).

Скриншот: `screenshots/hr-employees.jpg`

## Структура
- Страница «Сотрудники и HR», вкладка «Сотрудники», активная. Header-карточка над тулбаром.
- Тулбар: поиск («Поиск по имени, телефону, email...») + «Добавить сотрудника» + «Фильтры» (Offcanvas, включая кастомные фильтры по custom fields) + «Настроить столбцы» (своя модалка с drag-n-drop через `vuedraggable`, не `ColumnSettingsModal`).
- Чекбокс-колонка: да.
- Клик по строке — открывает Offcanvas «Панель просмотра» (`openPreview`), `cursor-pointer group`, чекбокс/действия — `@click.stop`.
- Колонки — динамические (`activeColumns`), включая catch-all для кастомных полей (`employee.custom_fields[col.key]`).
- Колонка «Действия»: **3** иконки (глаз-«Карточка»/карандаш/корзина) — «глаз» это `<Link>` на `hr.employees.show`, не кнопка.
- Строк на момент фиксации: 2 (Румянцев Роман Сергеевич — Менеджер/В штате/МДТЛ/Нет доступа; Гурьев Михаил Николаевич — Руководитель/В штате/МДТЛ/Нет доступа).

## Колонки
1. чекбокс
2. Сотрудник (`employee_name`) — аватар-круг с первой буквой имени + ФИО (полужирный, `group-hover:text-primary`) + телефон серым под ним
3. Должность / тип (`position_type`) — название должности (или «Без должности») + тип оформления серым под ним
4. Локация (`branch`) — серый бейдж с иконкой магазина
5. Доступ в CRM (`crm_access`) — если есть: зелёный бейдж «Есть доступ» + строка «Роль: ...» под ним; если нет: серый бейдж «Нет доступа»
6. Телефон / Email / Дата рождения / Дата приёма / Дата увольнения — простой текст (или «—»), опциональные колонки
7. Кастомные поля — catch-all `v-else` ветка, читает `employee.custom_fields[col.key]`
8. Действия — 3 иконки: `<Link>` глаз (Карточка, info-цвет) / карандаш (форма) / корзина (удалить)

## Консоль браузера на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- Клик по строке должен по-прежнему открывать Offcanvas Панели просмотра — `row-clickable @row-click="openPreview"`.
- Чекбокс и блок действий — `@click.stop` (уже встроено в `DataTable.vue` для чекбокса/actions-ячейки по умолчанию — доп. `.stop` для `<Link>` "Карточка" внутри `#actions` нужен отдельно, т.к. слот `actions` в целом не имеет своего `@click.stop` на всю ячейку... сверить, что `DataTable.vue` уже ставит `@click.stop` на td с `has-actions` — да, ставит).
- «Действия» — 3 иконки (не 2, как у большинства других таблиц) — не потерять «глаз»-ссылку на Карточку.
- Кастомные поля — динамические слоты `#cell-<key>` по `customFieldDefs`, аналогично паттерну CRM/Clients.
- Модалка «Настроить столбцы» — своя (drag-n-drop), НЕ трогается этим рефакторингом (вне `<table>`).

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (аватары-инициалы, бейдж локации, «Нет доступа», 3 иконки действий), ни одной ошибки в консоли. Клик по строке (вне действий) проверен вживую — открывает Offcanvas «Панель просмотра» с деталями сотрудника, как и раньше (`row-clickable @row-click="openPreview"`). Регресс не обнаружен.
