# Baseline: Settings/Payroll/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/payroll).

Скриншот: `screenshots/settings-payroll.jpg`

## Структура
- «Настройки компании», вкладка «Зарплата». Страница состоит из НЕСКОЛЬКИХ секций (общие тумблеры-настройки — форма, НЕ таблица; затем «Ставки по должностям» — таблица).
- Карточка «Ставки по должностям»: заголовок+кнопка «Добавить ставку» в шапке → блок клиентских фильтров (`SearchableMultiSelect` ×3: Должность/Локация/Группа услуг, + условная кнопка «Сбросить фильтры») → таблица.
- `positionRules` — простой массив (весь список), `filteredPositionRules` — клиентский computed-фильтр по трём мультиселектам. НЕТ серверной пагинации, НЕТ `DataTableToolbar`, НЕТ чекбокс-колонки.
- **ДВА разных пустых состояния**: «Ставки ещё не настроены» (весь список пуст) ИЛИ «Ничего не найдено по выбранным фильтрам» + инлайн-кнопка «Сбросить фильтры» внутри текста (если список непуст, но фильтр ничего не даёт) — `v-if`/`v-else-if`, не одно сообщение на оба случая.
- Строк на момент фиксации: 5 (Менеджер/Исполнитель ×3 категории — Химчистка/Мойка авто/Полировка, все 40.00%, Все локации; Руководитель/Администратор ×2 — обе «Категория: Полировка» 10.00%, Все локации — похоже на дубль данных, но это факт текущей БД, не баг рефакторинга).

## Колонки
1. Должность / Подрядчик — ДВА варианта (`v-if="rule.client"` / `v-else`): подрядчик — имя клиента + фиолетовый бейдж «Подрядчик»; должность — локализованное название + бейдж роли (primary «Администратор» / серый «Исполнитель»)
2. Применяется к — текст (`ruleTargetLabel(rule)`, например «Категория: Полировка»)
3. Локация — текст (`rule.branch.name` или «Все локации»)
4. Ставка — `text-right font-bold` (`ruleValueLabel(rule)`, например «40.00%»)
5. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- НЕТ `selectable`.
- Блок клиентских фильтров (SearchableMultiSelect ×3) — НЕ часть `<table>`, не трогается.
- ДВА разных пустых состояния (список пуст / фильтр ничего не нашёл, второе с инлайн-кнопкой сброса) — DataTable поддерживает только один `#empty` слот на компонент; условие внутри слота (`v-if="positionRules.length === 0"` / `v-else`) нужно перенести туда же.
- Колонка «Должность / Подрядчик» — двухвариантная ячейка (клиент-подрядчик vs штатная должность) с разным бейджем под именем.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (5 строк ставок, бейджи ролей, ставки справа). Оба пустых состояния проверены вживую через клиентские фильтры: выбор «Руководитель» корректно сузил список до 2 строк с появлением «Сбросить фильтры»; дополнительный выбор группы «Химчистка» (не пересекается с должностью) дал второе пустое состояние «Ничего не найдено по выбранным фильтрам. Сбросить фильтры» с рабочей инлайн-кнопкой сброса — оба условных состояния `#empty`-слота подтверждены, не только код прочитан. Ни одной ошибки в консоли. Регресс не обнаружен.
