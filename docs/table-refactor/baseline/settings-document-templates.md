# Baseline: Settings/DocumentTemplates/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/document-templates).

Скриншот: `screenshots/settings-document-templates.jpg`

## Структура
- «Настройки компании», вкладка «Шаблоны документов».
- Header-карточка с двумя кнопками: «Библиотека шаблонов платформы» + «Добавить шаблон» — НЕТ `DataTableToolbar` (нет поиска/фильтров), `templates` — простой массив без пагинации.
- НЕТ чекбокс-колонки.
- Колонки — статичные.
- Строк на момент фиксации: 2 («Акт выполненных работ» и «Счет на оплату», оба Заказ-наряд/HTML/Активен, разные префиксы нумерации).

## Колонки
1. Название — полужирный
2. Сущность — текст (`entityTypes[template.entity_type]`)
3. Источник — бейдж: синий с иконкой Word (если `format === 'docx'`, текст — `source_file_name` или «Word») ИЛИ серый с иконкой `</>` «HTML»
4. Нумерация — `number_prefix` (или «—») + « / год» суффикс если `number_reset_yearly`
5. Статус — зелёный «Активен» / серый «Выключен»
6. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- НЕТ `selectable` — на этой странице чекбоксов не было и не должно появиться.
- Условный бейдж «Источник» (docx/html) — сохранить оба варианта в одном слоте.
- Кнопка «Библиотека шаблонов платформы» и полноэкранная модалка редактора (`DocumentTemplateEditor.vue`) — вне `<table>`, не задеты рефакторингом.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (2 шаблона, бейдж HTML, статус «Активен»), ни одной ошибки в консоли. Регресс не обнаружен.
