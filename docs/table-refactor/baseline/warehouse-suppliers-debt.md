# Baseline: Warehouse/SuppliersDebt/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/warehouse/suppliers-debt).

Скриншот: `screenshots/warehouse-suppliers-debt.jpg`

## Структура
- Страница «Склад и Прайс», вкладка «Задолженность поставщикам».
- 3 KPI-карточки над таблицей (Общая задолженность/Поставщиков с долгом/Всего в расчётах) — не часть таблицы.
- Header-карточка таблицы с ссылкой «Все накладные →» — НЕТ `DataTableToolbar` (нет поиска/фильтров/пагинации), `suppliers` — простой массив.
- НЕТ чекбокс-колонки, НЕТ колонки «Действия» — клик по всей строке (`router.visit` на `crm.clients.show`), `cursor-pointer`.
- Колонки — статичные.
- Строк на момент фиксации: 1 (ООО "ЛЕРАТОН" — +79998887766/1 накладная/1 000₽/0₽/1 000₽).

## Колонки
1. Поставщик — полужирный + опциональный суффикс «(удалён)», если `supplier.is_deleted`
2. Телефон — текст (или «—»)
3. Накладных — число, `text-right`
4. Оприходовано — `text-right`
5. Оплачено — `text-success text-right`
6. Остаток — `text-right font-bold`, цвет условный: `text-danger` если баланс > 0, иначе `text-gray-400`

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- НЕТ `selectable`/`has-actions`.
- `row-clickable @row-click="s => router.visit(route('crm.clients.show', s.id))"`.
- KPI-карточки и ссылка «Все накладные →» вне `<table>`, не трогаются.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (ООО "ЛЕРАТОН", те же 6 колонок, цвет остатка), ни одной ошибки в консоли. Регресс не обнаружен.
