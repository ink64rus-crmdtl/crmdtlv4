# Baseline: Settings/CustomFields/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/custom-fields).

Скриншот: `screenshots/settings-custom-fields.jpg`

## Структура
- «Настройки компании», вкладка «Кастомные поля».
- Тулбар: поиск + «Добавить поле», `:has-filters="false"` (кнопка «Фильтры» есть визуально, но не подключена к логике — не менять это поведение).
- Чекбокс-колонка: да. Колонки — статичные.
- Строк на момент фиксации: 1 (Автомобиль / Пробег (`probeg`) / Текст, без доп. бейджей настроек).

## Колонки
1. чекбокс
2. Раздел — текст (`entityTypes[field.entity_type]`)
3. Название поля — жирный текст + серый `field.key` под ним
4. Тип — серый бейдж с рамкой (`fieldTypes[field.type]`)
5. Настройки — ДО 3 опциональных бейджей (`v-if` каждый): «Обяз.» (красный) / «Фильтр» (синий) / «В списке» (зелёный) — рядом через `space-x-2`
6. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- Колонка «Настройки» — до 3 независимых условных бейджей рядом, ни один не обязателен (сохранить точное поведение `v-if` на каждый).
- `tbody` в оригинале имел `divide-y divide-gray-200 dark:divide-gray-700` ПОМИМО обычных `border-b` на `<td>` — визуально задвоенная граница, не критично, но заметить при сверке (DataTable.vue не добавляет `divide-y` на `<tbody>`, только `border-b` на ячейках — визуальной разницы быть не должно, т.к. divide-y просто дублирует ту же границу).
