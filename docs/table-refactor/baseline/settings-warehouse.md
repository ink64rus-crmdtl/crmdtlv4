# Baseline: Settings/Warehouse/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/settings/warehouse).

Скриншот: `screenshots/settings-warehouse.jpg`

## Структура
- «Настройки компании», вкладка «Склад». Страница = форма выбора режима склада (3 карточки-варианта, НЕ таблица) + отдельная карточка «Склады» с таблицей ниже.
- Header-карточка «Склады» с кнопкой «Добавить склад» — НЕТ `DataTableToolbar`, НЕТ чекбокс-колонки, `warehouses` — простой массив.
- Колонки — статичные.
- Строк на момент фиксации: 1 («Основной склад» — Компания/★по умолчанию/Активен).

## Колонки
1. Название — жирный текст
2. Тип — синий бейдж «Компания» (`owner_type === 'company'`) ИЛИ серый бейдж с именем локации (`branchName(owner_id)`) + опциональная предупреждающая иконка (`ri-error-warning-line text-warning`), если тип склада не используется в текущем режиме
3. По умолчанию — жёлтая звезда (`ri-star-fill`) если `is_default`, иначе серый «—»
4. Статус — зелёный/красный бейдж
5. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- НЕТ `selectable`.
- Колонка «Тип» — условный бейдж (company/branch) + опциональная предупреждающая иконка рядом — все 3 варианта сохранить в одном слоте.
- Форма выбора режима склада (3 карточки) выше таблицы — не `<table>`, не трогается.

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (Основной склад, бейдж «Компания», звезда «по умолчанию», статус), ни одной ошибки в консоли. Регресс не обнаружен.
