# Baseline: Finance/Categories/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/finance/categories).

Скриншот: `screenshots/finance-categories.jpg`

## Структура
- Страница «Финансы и Кассы» — вкладки сверху (История операций / Статьи доходов и расходов / Остатки по дням / Закрытие периода), эта — вторая, активная.
- Тулбар: поиск («Поиск по названию...») + «Добавить статью» — **без кнопки «Фильтры»** (`:has-filters="false"` в `DataTableToolbar`), с кнопкой «Настроить столбцы» (иконка колонок).
- Чекбокс-колонка: да.
- Колонки — динамические (`activeColumns`, `listView`/`availableColumns`).
- Колонка «Действия»: 2 иконки (карандаш/корзина).
- Строк на момент фиксации: 0 («Статьи не найдены.») — в этом тенанте справочник статей пуст, реальных данных для сверки бейджей нет; типы ячеек подтверждены чтением исходника (`Finance/Categories/Index.vue`), не визуально.

## Колонки
1. чекбокс
2. Тип — цветной бейдж со стрелкой (зелёный «Доход» / красный «Расход»)
3. Название статьи — полужирный текст
4. Статус — зелёный/красный бейдж «Активно»/«Неактивно»
5. Действия — 2 иконки

## Консоль браузера на момент фиксации
Только Vite HMR debug.

## На что смотреть после рефакторинга
- Кнопки «Фильтры» в тулбаре по-прежнему НЕТ (не добавить случайно вместе с миграцией).
- Пустое состояние («Статьи не найдены.») рендерится тем же текстом через `emptyMessage`/`#empty`.
- Раз в тенанте нет строк — после миграции стоит либо создать тестовую статью через UI и сверить бейджи вживую, либо ограничиться сверкой по коду (структура ячеек 1:1 скопирована из оригинала).

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (пустое состояние), ни одной ошибки в консоли. Дополнительно создана живая тестовая запись через UI («Тестовая статья DataTable», тип Расход) — бейджи типа (красный «Расход»)/статуса (зелёный «Активно»), чекбокс-колонка, select-all (появление BulkActions-панели «Экспорт в Excel»/«Удалить выбранные»), иконки-действия (карандаш/корзина) — всё отработало корректно, запись затем удалена через иконку корзины, таблица вернулась в пустое состояние. Регресс не обнаружен.
