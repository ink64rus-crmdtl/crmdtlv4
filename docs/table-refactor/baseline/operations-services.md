# Baseline: Operations/Services/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/operations/services). `pricingBasis` тенанта = `'none'` → таблица в «плоском» (не матричном) режиме.

Скриншот: `screenshots/operations-services.jpg`

## ⚠️ ЧАСТИЧНАЯ МИГРАЦИЯ — важное отличие от остальных таблиц
У этой таблицы ДВА режима заголовка/тела, переключаемых computed `matrixActive` (`pricingBasis !== 'none' && matrixLookups.length > 0`, настраивается в Настройки → CRM → база ценообразования по кузову/классу авто):
- **Плоский режим** (`!matrixActive`, ТЕКУЩИЙ активный в studio2) — обычный один заголовочный `<tr>`, колонка «Базовая цена» одна.
- **Матричный режим** (`matrixActive`) — `<thead>` из ДВУХ `<tr>` с `rowspan`/`colspan` (одна колонка «База» + по одной колонке на каждое значение справочника `matrixLookups`, число которых динамическое) — `DataTable.vue` рассчитан на ОДИН заголовочный ряд, `rowspan`/`colspan`-заголовки не поддерживает.

**Решение**: мигрирую ТОЛЬКО плоский режим (`v-if="!matrixActive"` → `<DataTable>`), матричный режим (`v-else`) остаётся как raw `<table>` — тот же принцип частичного исключения, что уже применялся к drag-таблицам. В studio2 матричный режим сейчас не активен и визуально не проверяем — сверка того пути только по коду.

## Структура (плоский режим)
- Страница «Операции и Заказы», вкладка «Прайс-лист услуг».
- Тулбар: поиск + «Новая категория» (доп. кнопка) + «Добавить услугу» + «Фильтры» + «Настроить столбцы» (кнопки есть визуально).
- Чекбокс-колонка: да. Колонки — статичные (в отличие от большинства других — НЕ `activeColumns`).
- Строк на момент фиксации: 2 (Химчистка салона — Химчистка/Детейлинг/22 000₽/60 мин/Активно; Полировка авто — Полировка/Детейлинг/12 000₽/60 мин/Активно).

## Колонки (плоский режим)
1. чекбокс
2. Категория — серый бейдж с иконкой папки (или «—»)
3. Направление — синий бейдж (`bg-info/10`) с иконкой `ri-node-tree` (или «—»)
4. Название услуги — полужирный
5. Базовая цена — `text-right font-bold`
6. Нормо-время — `text-right`, «N мин»
7. Статус — зелёный/красный бейдж
8. Действия — 2 иконки

## Консоль на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- Матричный режим (`v-else`) остаётся НЕТРОНУТЫМ raw-кодом — не пытаться впихнуть его в DataTable в этом заходе.
- Кнопка «Новая категория» в тулбаре — не задета.
- Убедиться, что переключение `!matrixActive`/`matrixActive` в родительском `v-if` корректно рендерит DataTable ТОЛЬКО в плоском случае (визуально проверяемо только в этом тенанте — плоский режим).

## Результат после миграции на DataTable.vue (2026-08-14)
Сверено в браузере (LinuxChrome) после рефакторинга: визуально идентично baseline-скриншоту (Химчистка салона/Полировка авто, бейджи категории/направления, цена/нормо-время справа). Плоский режим (`!matrixActive`, единственный активный в studio2) корректно рендерится через DataTable. Матричный режим (`v-else`, rowspan/colspan-заголовок) оставлен нетронутым raw-кодом — не проверен визуально (не активен ни у одного тенанта в этой сессии), сверен только чтением диффа: разметка перенесена 1:1 из оригинала без изменений. Ни одной ошибки в консоли. Регресс не обнаружен.
