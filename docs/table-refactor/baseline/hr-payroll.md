# Baseline: HR/Payroll/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/hr/payroll).

Скриншот: `screenshots/hr-payroll.jpg`

## Структура
- Страница «Сотрудники и HR», вкладка «Взаиморасчёты», активная.
- **ДВЕ независимые таблицы на одной странице** (не список из нескольких переключаемых вкладками, а именно две подряд, как описано в CLAUDE.md §4 «Взаиморасчеты — Сотрудники и подрядчики показаны отдельными блоками»):
  1. «Взаиморасчёты с сотрудниками» — своя header-карточка + `DataTableToolbar` (поиск + ссылка «Настройки зарплаты», `:has-filters="false"`) + таблица + `<Pagination>`.
  2. «Взаиморасчёты с подрядчиками» — компактный блок с заголовком/иконкой прямо в шапке карточки (без `DataTableToolbar`, без поиска, без пагинации), рендерится только если `contractors.length > 0` (`v-if` на всём блоке — поэтому пустого состояния у этой таблицы в коде нет вообще).
- Обе таблицы: НЕТ чекбокс-колонки, НЕТ колонки «Действия» — клик по всей строке (`@click="router.visit(...)"`, `cursor-pointer`) ведёт на карточку сотрудника (`hr.employees.show`) / клиента (`crm.clients.show`).
- Колонки — СТАТИЧНЫЕ (не `activeColumns`) в обеих таблицах.
- Строк на момент фиксации: сотрудники — 2 (Гурьев Михаил/Руководитель/1 620₽/0₽/—/1 620₽; Румянцев Роман/Менеджер/3 660₽/0₽/—/3 660₽), подрядчики — 1 (Сергей Вмятины/+79998885555/1 000₽/0₽/1 000₽).

## Колонки (таблица 1 — Сотрудники)
1. Сотрудник — полужирный текст «Фамилия Имя»
2. Должность — текст (или «—»)
3. Начислено — `text-right`
4. Выплачено — `text-success text-right`
5. Штрафы — `text-danger text-right`, «− N ₽» если >0, иначе «—»
6. К выплате — `text-right font-bold`, цвет условный: `text-primary` если баланс > 0, иначе `text-gray-400`

## Колонки (таблица 2 — Подрядчики)
1. Подрядчик — полужирный текст + опциональный суффикс «(удалён)» серым, если `contractor.is_deleted`
2. Телефон — текст (или «—»)
3. Начислено — `text-right`
4. Выплачено — `text-success text-right`
5. К выплате — `text-right font-bold`, тот же условный цвет (primary/gray-400)

## Консоль браузера на момент фиксации
Без ошибок.

## На что смотреть после рефакторинга
- ДВЕ отдельные `<DataTable>` на странице — не пытаться объединить в одну.
- Ни в одной из двух — `selectable`/`has-actions` НЕ ставить (нет ни чекбоксов, ни действий).
- `row-clickable @row-click="row => router.visit(...)"` на обеих — сохранить переход на карточку по клику на всю строку.
- Условный цвет колонки «К выплате» (primary/gray-400 по знаку баланса) — передать через `cellClass`-подобный механизм или через сам слот (внутри слота можно применить `:class` к содержимому, раз у DataTable нет per-row динамического `cellClass`).
- Блок «Подрядчики» целиком скрыт при `contractors.length === 0` — эта видимость на уровне родительского `<div v-if>`, не трогается рефакторингом `<table>`.
- Таблица подрядчиков без пагинации/тулбара — не добавлять их ошибочно.
