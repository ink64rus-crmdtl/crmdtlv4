# Baseline: Finance/Transactions/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/finance/transactions).

Скриншот: `screenshots/finance-transactions.jpg`

## Структура
- Страница «Финансы и Кассы», вкладка «История операций», активная.
- Над таблицей — блок 4 карточек-виджетов дашборда балансов (Общий баланс + до 3 счетов) — НЕ часть таблицы.
- Тулбар: поиск («Поиск по комментарию...») + «Новая операция» + «Фильтры» (Offcanvas, много полей) + «Настроить столбцы».
- Чекбокс-колонка: да.
- Колонки — динамические (`activeColumns`), с особым выравниванием: `amount` — `text-right`, `reconciled` — `text-center`, остальные — по умолчанию.
- Колонка «Действия»: 2 иконки БЕЗ подложки-круга (карандаш/возврат-стрелка, обычные текстовые цветные иконки `text-primary`/`text-danger`, не `bg-*/10 rounded-full` паттерн, как у других таблиц) — отклонение от общего паттерна CLAUDE.md §7, сохранить как есть при миграции.
- Строк на момент фиксации: 1 (5 авг. 2026, Доход, МДТЛ, Касса, —, +17 000 ₽, «Заказ-наряд #000001» ссылкой + «Оплата по заказ-наряду #1»).

## Колонки
1. чекбокс
2. Дата — текст + необязательная иконка карандаша (если `edited_at` есть) с title о времени/авторе правки
3. Тип — цветной бейдж со стрелкой (Доход зелёный / Расход красный / Перевод синий)
4. Локация — серый бейдж с иконкой магазина, суффикс «(удалена)» если `branch.deleted_at`
5. Счет / Касса — текст
6. Статья — текст (или «—»)
7. Сумма — цветное число с знаком (+зелёный/-красный/без знака серый), `text-right font-bold`
8. Основание / Комментарий — двухстрочная: опциональная синяя ссылка «Заказ-наряд #NNNNNN» (только если `payable_type === 'App\\Models\\WorkOrder'`) сверху + серый комментарий снизу
9. Сверено — круглая кнопка-иконка (банк), зелёная активная / серая неактивная, `text-center`, `@click` переключает сверку (НЕ просто ячейка отображения — интерактивный виджет прямо в таблице)
10. Действия — 2 плоские иконки (карандаш редактировать / возврат-стрелка отменить), без круглой подложки

## На что смотреть после рефакторинга
- Выравнивание `amount`(right)/`reconciled`(center) — обязательно передать через `align` в конфиге колонок (не забыть, единственная страница с двумя разными спец-выравниваниями сразу).
- Колонка «Сверено» — интерактивная кнопка внутри ячейки, а не текст; клик должен продолжать работать через `@click.stop` (иначе всплывёт `row-click`, если он вообще будет использоваться — сейчас его нет).
- Колонка «Действия» — иконки БЕЗ круглой подложки (в отличие от большинства других мигрированных таблиц) — не «улучшать» её ненароком под общий паттерн, это осознанное отличие исходной вёрстки.
- Дашборд-карточки балансов над таблицей не задеты.
- Offcanvas «Фильтры» и модалка операции продолжают открываться/работать как раньше.
