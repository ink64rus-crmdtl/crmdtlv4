# Baseline: Warehouse/Balances/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/warehouse/balances).

Скриншот: `screenshots/warehouse-balances.jpg`

## Структура
- Та же страница «Склад и Прайс», вкладка «Остатки на складах».
- Тулбар: поиск + «Оприходовать товар» + «Фильтры» + «Настроить столбцы» (без «Добавить» — это read-проекция, не CRUD-список).
- Чекбокс-колонка: да.
- **Колонка «Действия» — НЕТ ВООБЩЕ** (в отличие от остальных пилотов). `StockBalanceController` — тот самый контроллер, который НЕ использует `QueryFilterService::apply()`, дублирует sort-логику руками (см. план рефакторинга сортировки, отдельная задача).
- Колонки — динамические (`activeColumns`).
- Строк на момент фиксации: 1 (Основной склад / Линзы для фар / Линза А-001 / 3 шт / 0₽ / 0₽).

## Колонки
1. чекбокс
2. Склад — иконка + название
3. Категория
4. Товар / Артикул — двухстрочная ячейка (название полужирным + артикул серым под ним)
5. Остаток — «3 шт», полужирный, по центру/справа
6. Ср. себестоимость
7. Общая стоимость

## Консоль браузера на момент фиксации
Только Vite HMR debug.

## На что смотреть после рефакторинга
- **Без колонки «Действия»** — `has-actions` НЕ ставить (иначе появится лишний пустой столбец справа).
- Двухстрочная ячейка «Товар / Артикул» переживает перенос в слот без потери форматирования.
