# Baseline: Warehouse/Products/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/warehouse/products).

Скриншот: `screenshots/warehouse-products.jpg`

## Структура
- Страница «Склад и Прайс» — 5 вкладок сверху (Товары и Материалы / Остатки на складах / Приходные накладные / Задолженность поставщикам / Движения), эта — первая, активная.
- Пагинация: серверная, 1 строка на момент фиксации.
- Тулбар: поиск («Поиск по названию или артикулу») + «Новая категория» (отдельная кнопка, не «Добавить») + «Добавить товар» + «Фильтры» + «Настроить столбцы».
- Чекбокс-колонка: да.
- Колонки — динамические (`activeColumns`).
- Колонка «Действия»: 2 иконки (карандаш/корзина) — БЕЗ «глаза»/карточки (в отличие от Clients/Vehicles/Branches).
- Строк на момент фиксации: 1 («Линза», категория «Линзы для фар», артикул А-001, партионный учёт FIFO).

## Колонки
1. чекбокс
2. Категория — текст с иконкой папки
3. Артикул
4. Название — полужирный
5. Ед. изм.
6. Тип учёта — цветной текст (жёлтый «Партионный (FIFO)» на скриншоте — уточнить цвет для «Средневзвешенный» отдельно при миграции, в этой БД только партионный тип встретился)
7. Статус — зелёный бейдж «Активно»
8. Действия — 2 иконки
