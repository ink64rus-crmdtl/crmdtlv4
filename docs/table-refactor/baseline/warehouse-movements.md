# Baseline: Warehouse/Movements/Index.vue

Зафиксировано: 2026-08-14, тенант studio2 (studio2.localhost:8000/warehouse/movements).

Скриншот: `screenshots/warehouse-movements.jpg`

## Структура
- Та же страница «Склад и Прайс», вкладка «Движения» — согласно CLAUDE.md, «read-only лентой», журнал движений.
- Тулбар: поиск + «Фильтры» + «Настроить столбцы» (без кнопки добавления — это чистый лог).
- Чекбокс-колонка: да.
- **Колонка «Действия» — НЕТ** (та же ситуация, что у Balances — read-only лента).
- Колонки — динамические (`activeColumns`).
- Строк на момент фиксации: 3 (два прихода + один расход по одной и той же Линзе).

## Колонки
1. чекбокс
2. Дата — «13 авг., 22:54»
3. Тип — цветной бейдж с иконкой стрелки («Расход» — красный, стрелка вверх-вправо; «Приход» — зелёный, стрелка вниз-влево)
4. Склад / Локация — двухстрочная: название склада с иконкой + бейдж локации («МДТЛ») под ним
5. Товар — двухстрочная: название полужирным + «Партия #N» жёлтым под ним (партионный учёт)
6. Кол-во — «-1 шт»/«+1 шт»/«+3 шт», цветное (красное/зелёное соответственно знаку)
7. Себестоимость
8. Основание — синяя ссылка («Заказ #000001», «Накладная №000001 (...)») ИЛИ обычный серый текст («Оприходование товара») — зависит от того, есть ли связанная запись

## Консоль браузера на момент фиксации
Только Vite HMR debug.

## На что смотреть после рефакторинга
- **Без колонки «Действия»**.
- Колонка «Основание» — смешанный тип ячейки (иногда `<Link>`, иногда голый текст) — оба варианта должны сохраниться через один и тот же слот с условным `v-if`.
- Цвет «Кол-во» (+ зелёный / − красный) и цвет бейджа «Тип» (Приход зелёный / Расход красный) — не перепутать местами при переносе классов.
